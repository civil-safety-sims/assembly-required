# Assembly Required

**A Protest Safety Simulator.**
Built for the 2026 Global Game Jam.

_"You have the right to assemble. But are you ready?"_

## ⚠️ Mission Statement
This is a game about **harm reduction**. It uses verified data from the EFF, National Lawyers Guild, and Physicians for Human Rights to teach real-world protest safety.

**The Goal:**
Manage your "Paper Doll" loadout against changing variables (Weather, Police Aggression, Duration) to see if you are prepared for the reality of civil action.

## 🛡️ Data Sources
All safety advice in this application is strictly sourced from:
* **EFF:** Surveillance Self-Defense
* **NLG:** Know Your Rights
* **CPJ:** Physical Safety: Civil Disorder
* **PHR:** Tear Gas & Chemical Irritants
